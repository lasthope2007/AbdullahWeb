# Abdullah Zare — Personal Portfolio

وب‌سایت شخصی **عبدالله زارع** — دانشجوی مهندسی کامپیوتر و توسعه‌دهنده نرم‌افزار.
ساخته‌شده با **HTML5، CSS3 و جاوااسکریپت خالص (ES6+)** — بدون هیچ فریم‌ورک یا وابستگی خارجی.

- دامنه: <https://abdullahzare.ir>
- گیت‌هاب: <https://github.com/lasthope2007>
- ایمیل: `lasthopedevice@gmail.com`

## ساختار پروژه

```

├── about.html                معرفی، فلسفه‌ی یادگیری، مهارت‌ها، تحصیل

├── projects/                 ۶ صفحه‌ی جزئیات پروژه
├── writing/articles/         ۶ صفحه‌ی مقاله (نمونه — قابل ویرایش)
├── assets/
│   ├── logo/az-logo.png      لوگوی اصلی AZ (بدون تغییر)
│   ├── icons/                فاویکون‌ها و آیکون‌های دستگاه

├── js/   main.js · theme.js · projects.js · search.js

```

## اجرای محلی

هیچ build و نصبی لازم نیست:

```bash
# با پایتون
python -m http.server 8000
# سپس http://localhost:8000 را باز کنید
```

یا از افزونه‌ی **Live Server** در VS Code استفاده کنید. باز کردن مستقیم `index.html` هم کار می‌کند
(فونت‌ها و همه‌ی امکانات به‌جز clipboard در حالت `file://` هم کار می‌کنند).

## ویرایش محتوا

| چه چیزی | کجا |
| --- | --- |
| پروژه‌ها (متن، فناوری، لینک‌ها) | مستقیم در فایل‌های `projects/*.html` و بخش‌های مربوط در `index.html` / `projects.html` |
| مقاله‌ها | فایل‌های `writing/articles/*.html` |
| لینک اینستاگرام و لینکدین | `js/main.js` → بخش `AZ_SITE` (اگر خالی بماند، ردیف «در انتظار تکمیل» نمایش داده می‌شود) |
| اسکرین‌شات پروژه‌ها | در `assets/images/` ذخیره و جای پنل جای‌نگهدار در صفحه‌ی پروژه قرار دهید |

نکته‌ها:

- نوشتارهای فعلی صریحاً «نمونه» برچسب خورده‌اند؛ بعد از نوشتن متن واقعی، برچسب و باکس اطلاع‌رسانی را حذف کنید.
- لینک‌های مخزنی که هنوز عمومی نیستند (NEXUS، مخزن همین سایت) به‌صورت صادقانه «در انتظار» علامت خورده‌اند؛ پس از انتشار، جای `<span class="link-disabled">` را با لینک واقعی عوض کنید.
- لوگوی AZ دقیقاً همان فایل آپلودشده است؛ آن را بازطراحی یا تغییر ندهید.

## استقرار روی GitHub Pages

1. یک مخزن جدید بسازید (مثلاً `abdullahzare.ir` یا `<username>.github.io`) و محتوای این پوشه را push کنید.
2. در تنظیمات مخزن: **Settings → Pages → Build and deployment → Source: Deploy from a branch**، شاخه‌ی `main` و پوشه‌ی `/ (root)` را انتخاب کنید.
3. پس از چند دقیقه سایت روی `https://<username>.github.io/<repo>/` در دسترس است.
4. دامنه‌ی اختصاصی: در **Settings → Pages → Custom domain** مقدار `abdullahzare.ir` را وارد کنید و در DNS:
   - رکورد `A` برای ریشه: `185.199.108.153`، `185.199.109.153`، `185.199.110.153`، `185.199.111.153`
   - رکورد `CNAME` برای `www` به `<username>.github.io`
5. تیک **Enforce HTTPS** را بزنید. (اختیاری: یک فایل `CNAME` حاوی `abdullahzare.ir` در ریشه بسازید تا دامنه پس از redeploy حفظ شود.)

## استقرار روی Vercel

1. پروژه را در گیت‌هاب نگه دارید و در <https://vercel.com/new> ایمپورت کنید.
2. تنظیمات: **Framework Preset: Other**، بدون Build Command، **Output Directory: `./`** (ریشه‌ی مخزن).
3. Deploy بزنید؛ پس از انتشار، از **Settings → Domains** دامنه‌ی `abdullahzare.ir` را اضافه کنید و رکوردهای DNS پیشنهادی Vercel را در پنل دامنه‌تان ثبت کنید.

## SEO

- عنوان و توضیح متای اختصاصی برای هر صفحه، Open Graph و Twitter Card، canonical URLها.
- داده‌ی ساخت‌یافته JSON-LD: `Person` (خانه/درباره)، `Article` (مقاله‌ها)، `BreadcrumbList` (صفحات جزئیات).
- `sitemap.xml` و `robots.txt` آماده‌اند؛ پس از انتشار آدرس canonicalها روی `abdullahzare.ir` اعمال می‌شود.

## تست‌های انجام‌شده پیش از تحویل

- همه‌ی صفحه‌ها در مرورگر واقعی (دسکتاپ و موبایل) باز و بررسی شدند؛ ناوبری، تم روشن/تیره، فیلتر پروژه‌ها، جستجوی نوشتارها و دکمه‌ی بازگشت به بالا تست شدند.
- همه‌ی لینک‌های داخلی بررسی شدند (اسکریپت بررسی لینک) و هیچ لینک شکسته‌ای باقی نمانده است.
- کنسول مرورگر بدون خطا است.
